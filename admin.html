Resetează contul de administrator

Contul este salvat în repo (criptat cu parola ta), astfel încât să te poți autentifica cu nume + parolă de pe orice dispozitiv.

Tokenul este criptat (AES-GCM, cheie derivată din parolă) înainte de a fi salvat în repo.
Cum obții tokenul? (2 minute)
  1. Intră pe github.com/settings/personal-access-tokens/new.
  2. Repository access: Only select repositories → alege Mckyto/caleidoscope-educational.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate → copiază tokenul (începe cu github_pat_) aici.
Bifezi doar pe dispozitivele tale private — salvează tokenul decriptat local (localStorage).
